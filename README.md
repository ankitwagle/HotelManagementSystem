# Hotel Management System (HMS)

A full-stack hotel management web application built with PHP and MySQL. It lets guests book rooms online and gives admins tools to verify bookings and manage payments.

> 🚧 **Status:** In progress — payment gateway integration is the last major piece being completed.

## Features

- 🏨 **Room Booking** — Users can browse and book available rooms
- ✅ **Admin Verification** — Admin panel to review and verify bookings
- 💳 **Payments** — Booking payments handled through the system *(gateway integration in progress)*
- 🗄️ **Database-backed** — All bookings, users, and room data persisted in MySQL

## Tech Stack

- **Frontend/Backend:** PHP (full stack)
- **Database:** MySQL (managed via phpMyAdmin)
- **Environment:** Localhost / Wampp

## Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/ankitwagle/HotelManagementSystem.git
   ```
2. Set up a local server environment (e.g. XAMPP/WAMP) with PHP and MySQL.
3. Import the database using phpMyAdmin.
4. Update database connection details in the config file.
5. Run the project on your local server (http://localhost:8000/index.php).
